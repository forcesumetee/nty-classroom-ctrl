NTY Classroom Control — Word Exam Template Format
==================================================

อาจารย์เขียนข้อสอบใน Word ตามรูปแบบนี้ ระบบจะ parse และนำเข้าได้อัตโนมัติ
ไม่ต้องใช้ AI — parse แบบ deterministic ตรวจสอบเฉลยได้เอง

ตัวอย่าง:

[QUESTION]
ข้อใดคือเมืองหลวงของประเทศไทย?
ก. เชียงใหม่
ข. กรุงเทพมหานคร
ค. ภูเก็ต
ง. ขอนแก่น
[ANSWER] ข
[POINTS] 1

[QUESTION]
1 + 1 เท่ากับเท่าไหร่?
[IMAGE: math.png]
A. 1
B. 2
C. 3
D. 4
[ANSWER] B
[POINTS] 2

[QUESTION]
ข้อใดเป็นภาษาโปรแกรมแบบ object-oriented? (เลือกได้มากกว่า 1)
ก. C++
ข. HTML
ค. Java
ง. CSS
[ANSWER] ก,ค
[POINTS] 2

หลักการ:
- เริ่มแต่ละข้อด้วย [QUESTION] บรรทัดเดียว
- บรรทัดถัดไปคือคำถาม (หลายบรรทัดได้)
- ใส่ [IMAGE: filename.png] ถ้ามีรูป (รูปต้อง embed ใน Word)
- choices ขึ้นต้นด้วย ก./ข./ค./ง. หรือ A./B./C./D.
- [ANSWER] ตามด้วยตัวอักษรเฉลย (เครื่องหมายจุลภาคสำหรับหลายคำตอบ)
- [POINTS] ตามด้วยคะแนน (ไม่ใส่ = 1 คะแนน default)
- บรรทัดว่างคั่นระหว่างข้อ
